## About

This project was created to answer two questions; "How could I make playing Minecraft with my friends a better experience?", and the subsequent question of "Can I make my own Discord Bot?". The answer to the latter, thankfully, was yes!

Written in Python, this Minecraft Discord Bot strives to make playing Minecraft easier, but also more fun. It has audio capabilities, crafting recipe lookups and a trivia functionality for game nights when you want to take a break from mining and crafting. Bonus points because I actually used it a few times and found it very useful.

Feel free to use this Minecraft Discord Bot as is, as a launch pad for a better iteration, or even as a template for a completely differently themed Discord Bot. Just make sure to have fun doing it!
